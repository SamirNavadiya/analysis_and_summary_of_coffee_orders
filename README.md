# Coffee Orders Analysis Project

## 📌 Project Overview
This project processes and analyzes coffee order data to provide useful insights into sales trends, customer preferences, and order summaries. The raw data is transformed into structured reports, visualizations, and a dashboard for better decision-making.

## 📂 Files and Structure

### **1️⃣ Raw Data (coffeeOrdersData.xlsx)**
Contains three sheets:
- **Orders**: Tracks individual orders with product and customer IDs.
- **Customers**: Contains customer details like name, email, phone, and address.
- **Products**: Provides details on coffee types, pricing, and profit margins.

### **2️⃣ Processed Data & Analysis (coffeeOrdersProject.xlsx)**
Enhanced with calculated metrics and visualizations across **seven** sheets:

- **Orders** (Expanded to 16 columns)
- **Customers** (Same as raw data, used for reference)
- **Products** (Same as raw data, used for reference)
- **Top5Customers** (Lists top customers based on total sales)
- **CountryBarChart** (Shows sales breakdown by country)
- **TotalSales** (Monthly sales data categorized by coffee type)
- **Dashboard** (Interactive Coffee Sales Dashboard with filters and visualizations)

## 📊 Dashboard Features
The dashboard provides key insights into coffee sales with interactive charts and filters:
1. **Total Sales Over Time** (Line Chart)
2. **Sales by Country** (Bar Chart)
3. **Top 5 Customers** (Bar Chart)

### **Dashboard Filters**
- **Timeline Filter** (Jan 2019 - Dec 2022)
- **Roast Type Filter** (Dark, Light, Medium)
- **Size Filter** (0.2kg, 0.5kg, 1.0kg, 2.5kg)
- **Loyalty Card Filter** (YES/NO)

## 🚀 How to Use
1. Download and open the `coffeeOrdersProject.xlsx` file.
2. Navigate to the **Dashboard** sheet to view visual insights.
3. Apply filters to analyze specific trends.
4. Explore individual sheets (`Top5Customers`, `CountryBarChart`, `TotalSales`) for detailed breakdowns.
